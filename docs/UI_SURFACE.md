# 界面可见功能

手机屏幕上**真的能看到、能点**的东西，按屏幕区域拆到最小单位。

与 [FEATURES.md](FEATURES.md) 的分工：那份从代码出发，含大量用户看不见的后端机制（可靠投递、审计、协议桥接）；这份只收界面上存在的交互面。

**核对方式**：2026-09-10 在 375×812 视口用 mock app-server 实跑，逐个元素量 `getBoundingClientRect` + `getComputedStyle`。带 ⚠ 的是 HTML 里存在但视觉上看不到的元素——列出来是为了避免下次有人以为它们在工作。

---

## 1. 顶栏（常驻）

| 元素 | 看到什么 | 点了做什么 |
|---|---|---|
| 会话按钮 + 状态点 | 图标，右下角圆点表示连接状态 | 打开左侧抽屉 |
| 延迟胶囊 | `延迟 2ms`，慢时变色 | — |
| 项目胶囊 | 当前工作区名，右侧可带改动数徽标 | 打开工作区面板 |
| 首页按钮 | 房子图标 | 回到空会话 |
| 新建按钮 | 加号图标 | 创建新会话 |
| 工作区下拉 | 仅配置了多个 `WORK_DIRS` 时出现 | 切换工作区 |

⚠ **顶栏里看不到的**：`#thread-title`（会话名）和 `#state-label`（idle/busy）虽有内容，但高度被压成 1px + `overflow:hidden`；`#session-meta` 和 `#status-detail` 是 `display:none`，全表没有规则打开它们。

## 2. 左侧抽屉

### 2.1 会话列表

- 按项目分组的会话列表，显示标题与相对时间
- **已归档**切换按钮（固定在滚动区外，不会被长列表滚走）
- 每条会话长按/侧滑出操作：重命名、归档、删除

### 2.2 工具面板（12 个按钮，全部可见）

| 按钮 | 打开后看到 |
|---|---|
| Threads | 原生会话列表 |
| Compact | 压缩当前上下文 |
| Rollback | 回退 N 轮（要求输入轮数） |
| Models | 模型能力列表 |
| Files | 只读文件浏览器 |
| Account | 账号、用量、速率限制 |
| MCP | MCP 服务器状态 |
| 诊断 | 分层连接诊断结果 |
| 设备 | 已接入设备列表，可撤销 |
| Skills | Skills 列表与启用状态 |
| Import | 探测并导入 AGENTS.md / CLAUDE.md |
| 宿主配置 | 改 config、插件、marketplace、MCP 调用、登出（红色标记，每项单独确认） |

⚠ **开启推送通知**按钮只在浏览器支持且 VAPID 三项配齐时出现。

## 3. 消息流

### 3.1 空会话

- 大标题「我们来构建什么？」+ 当前项目名
- 四张建议卡片：探索并理解代码 / 构建新功能、应用或工具 / 审查代码并提出修改建议 / 修复问题和失败（点击填入输入框）

### 3.2 有消息时

| 卡片 | 看到什么 |
|---|---|
| 用户气泡 | 右对齐，含附件缩略图 |
| 助手气泡 | Markdown 渲染：标题、表格、引用、列表、分隔线 |
| 代码块 | 语法高亮 + 复制按钮，暗底 |
| 宽表格 | 自己横向滚动，不撑破气泡 |
| thinking / reasoning | 可折叠，默认收起 |
| 命令卡片 | 命令、退出码、输出（流式增量） |
| 文件变更卡片 | 路径、增删行数、diff |
| MCP 调用卡片 | 服务器名、工具名、参数与结果 |
| 搜索结果卡片 | 标题、URL、摘要 |
| 计划卡片 | 待办列表与状态 |
| Raw 卡片 | 未识别的 item 降级显示，不静默丢弃 |
| 系统消息 | 灰色居中，错误为红色 |
| turn 终态 | 完成 / 失败 / 中断的摘要 |

### 3.3 审批与提问（出现在消息流里）

- 命令执行审批卡：命令正文 + 批准/拒绝按钮
- 文件改动审批卡、权限升级审批卡
- agent 提问表单：自由文本或选项按钮
- 审批被上游撤销时卡片自动关闭

### 3.4 浮层

- **需要你**面板：跨会话待办聚合，点击跳到对应会话
- **待批准设备**面板：新设备接入时出现
- **连接横幅**：连接中 / 断开 / 重连中 / 立即重试按钮
- **有新内容 ↓**：滚动位置不在底部且有新消息时出现

## 4. 输入区（常驻）

| 元素 | 看到什么 | 操作 |
|---|---|---|
| 输入框 | 占位符「接下来我们该写什么代码？」，自动增高 | 输入消息 |
| 设置胶囊 | `GPT-5.6 · 请求批准`（模型 · 权限，可带模式与强度） | 打开会话设置 |
| 上下文表 | `36k/272k`，逼近上限变黄/红 | 有用量后才出现 |
| 附件按钮 | 回形针 | 选文件；也支持粘贴图片 |
| 发送按钮 | 有内容时出现 | 发送 |
| 追加按钮 | turn 进行中出现 | 追加到当前任务或排队 |
| 停止按钮 | turn 进行中，替代发送按钮 | 中断当前 turn |
| 加载指示 | turn 进行中的小转圈 | — |
| 附件托盘 | 缩略图列表 | 点击预览、× 移除 |

**输入时触发的浮层**：

- `/` → 斜杠命令面板：`/help`、`/status`、`/plan`、`/diff`、`/review`、`/compact`、`/permissions`（每条带说明，可继续输入过滤）
- `@` → 工作区文件搜索，选中后插入引用

## 5. 会话设置面板

点设置胶囊打开。**权限**（4 项）：

| 选项 | 含义 |
|---|---|
| 请求批准 | 逐次审批（默认） |
| 帮我批准 | 自动审查 |
| 完全访问 | 免审批 + 完全沙箱（需二次确认） |
| 跟随主机配置 | 用宿主机 config.toml 的设置 |

下方一行状态说明：`所选设置将在下一轮生效` / `当前已生效` / `主机配置已应用`。主机策略禁止的模式显示为不可选并给出原因。

**模型**（来自 `model/list`，mock 下 4 个）、**推理强度**（低/中/高/超高/最大）、**速度**（标准/快速）。

**会话模式**：对话模式（Chat）可选；计划模式（Plan）**固定禁用**，提示「当前稳定协议尚未提供已验证的模式切换能力」。

**高级设置**（默认折叠）：

- 审批策略：仅信任命令 / 按请求批准 / 从不询问
- 审批人：由我审批 / 自动审查
- 细粒度审批：沙箱外操作、规则匹配、技能调用、权限申请、MCP 追问
- 沙箱：只读 / 工作区可写 / 完全访问
- 当前生效值：JSON 原文（未拿到时显示「等待当前会话返回配置」）

---

## 6. 工作区面板

点顶栏项目胶囊打开，两个标签页：

**文件**：目录浏览（进入子目录、← 返回、当前路径）、文件预览（前 8000 字符）、「引用到输入框」按钮。

**改动**：分支名、刷新按钮、按 已暂存 / 未暂存 / 未跟踪 / 冲突 分组的文件列表，点文件看 diff（增删行着色）。

---

## 7. 全屏对话框

| 对话框 | 何时出现 |
|---|---|
| 访问口令 | 未认证时，输入 `AUTH_TOKEN` |
| 等待设备授权 | 新设备待批准，显示设备 ID 和批准命令 |
| 确认 sheet | 危险操作前（删除、完全访问、宿主配置…），部分需输入确认文本 |
| 附件预览 | 点附件缩略图，全屏看图 |

---

## 8. 全局表现

- 浅色 / 深色跟随系统
- 软键盘弹出时布局自适应（`visualViewport`）
- 可安装为 PWA（Service Worker + manifest）
- 后台时通过 Web Push 收审批、结果、错误、权限变更、进程退出通知
- turn 完成有无障碍播报（屏幕阅读器可听，视觉上不可见）

## ⚠ 界面上看不到的元素

实跑测量确认，以下在 HTML 里存在但用户看不到。列出来是为了避免误以为它们在工作：

| 元素 | 状态 | 说明 |
|---|---|---|
| `#thread-title` | 高 1px + overflow:hidden | 有内容（会话名）但视觉不可见 |
| `#state-label` | 高 1px + overflow:hidden | 有内容（idle/busy）但视觉不可见 |
| `#session-meta` | `display:none` | 全表无规则打开 |
| `#status-detail` | `display:none` | 全表无规则打开；上下文占用因此改放 composer |
| `#model-input` | `display:none` | HTML 注释标为 legacy 兼容字段 |
| `#perm-select` | `display:none` | 同上 |
| `#turn-announcer` | `.sr-only` | 有意的：只给屏幕阅读器 |
